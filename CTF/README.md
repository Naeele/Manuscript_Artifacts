# Welcome to the Thesis CTF!

Welcome to this small **Capture The Flag (CTF)** challenge, specially designed to accompany my PhD thesis manuscript.

This CTF consists of **six challenges**, each with their flag linked to an element from one of the six chapters of the thesis. The challenges are intentionally accessible: they are inspired by the activities I have used during mediation sessions with middle- and high-school students, although they have been adapted for this manuscript.

## Rules

* There are **6 levels** in total.
* Each level contains a **secret flag**, which is a single word.
* The flag obtained at level *n* is the password required to open the archive corresponding to **Level_(n+1).7z**.

### Extracting a `.7z` archive

To extract a file named `Level_i.7z`:

1. Open a terminal in the directory containing the archive.
2. Run the following command:
   ```bash
   7z x Level_i.7z
   ```
3. When prompted, enter the flag you obtained from the previous level as the password.

If the password is correct, the contents of the archive will be extracted and the next challenge will be revealed.
