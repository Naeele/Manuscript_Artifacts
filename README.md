# Thesis Artifacts

This repository contains supplementary material associated with my PhD thesis.

To facilitate reproducibility, all figures and supplementary results associated with the first two chapters of the manuscript are available in this repository.

## Repository Structure

```text
.
├── CTF/
├── Fig_1-1_artifact/
├── Fig_2-7_artifact/
└── Figures/
```

### CTF

The `CTF` directory contains a small and *easy* Capture The Flag (CTF) challenge designed specifically for this manuscript.

The challenges are inspired by activities I created and tested with middle- and high-school students during mediation events, and were later adapted to fit the topics and themes of the thesis.

Participation is entirely optional and is not required to understand the manuscript. However, attentive readers who complete all the challenges may receive a small gift as a reward for their perseverance and curiosity. :)

### Fig_1-1_artifact

This directory contains the scripts, data, and instructions required to reproduce **Figure 1.1** of the manuscript.

### Fig_2-7_artifact

This directory contains the scripts, data, and instructions required to reproduce **Figure 2.7** of the manuscript.

The artifacts associated with Figures 1.1 and 2.7 are provided here because they were not included in the companion artifacts of the corresponding publications.

### Figures

This directory contains all figures appearing in the manuscript that are not directly generated by LaTeX.

Figures generated entirely using TikZ are not duplicated here, as they can be reproduced directly from the manuscript sources (available once the defense is complete).
